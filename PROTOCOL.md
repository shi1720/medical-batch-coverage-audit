# Exploratory protocol and documented amendments

Date: 2026-10-11. Status: exploratory research protocol, not a registered study.

Question: does changing only companion images invalidate prediction-set coverage in batch-adaptive medical image classification, and what is the efficiency cost of simultaneously protecting a finite menu of companion contexts?

Scope: a controlled benchmark study; not a novel batch-normalization algorithm or a new general conformal theorem. Max-score calibration is an application of existing robust conformal prediction. Novelty to assess: the scheduling intervention, simultaneous rather than per-context outcome, and its measured medical-image consequences. Do not claim firstness without evidence.

Data: official 28-pixel PneumoniaMNIST, BreastMNIST and DermaMNIST archives. Train on official train, select checkpoint using official validation negative log likelihood. Split official test randomly, without label stratification, into calibration/evaluation halves using independent random seed 20406. Preserve all indices. No patient identifiers available in archives: image-level inference only, no assertion of patient-level independent testing.

Models: a three-block convolutional classifier with batch normalization (CNN-BN), a small residual classifier (ResNet-BN), and the same convolutional classifier with group normalization (CNN-GN). Five training seeds 0--4. AdamW, 25 epochs, learning rate 0.001, weight decay 0.0001, batch 64. No augmentation. Source pixel normalization x/127.5-1. Checkpoint chosen by validation NLL. CPU two threads; no interaction with other chats.

Contexts: 15 source training images plus the unchanged query (batch 16). Three independent context replicates. Each replicate has one natural-frequency context, one class-balanced context, and one class-homogeneous context for each class. Context draws use seed 801+r; class labels are used solely to construct a controlled stress test, not for any deployed algorithm. Context menu is fixed independently of calibration/evaluation labels. Sampling without replacement within a context when possible, otherwise with replacement (recorded). Images and identities are fixed across models and seeds.

Normalization controls on the same trained weights: frozen source statistics; current-group statistics; fixed 50:50 interpolation of source and target first/second moments; adaptation of first normalization layer only. GroupNorm is an independently trained, companion-independent control. Every query is evaluated with its own context; concatenating queries into one shared BN batch is forbidden. Learned weights and affine parameters remain frozen at inference. This is not Tent or continual TTA.

Primary score: 1 minus predicted true-label probability. Miscoverage alpha=0.10. Finite-sample corrected order statistic ceil((n+1)*(1-alpha)), infinity when rank exceeds n. Methods: nominal calibration under first natural context; context-specific calibration; Bonferroni context-specific calibration alpha/M; envelope calibration of maximum score across all contexts. Context-specific and envelope thresholds use the same calibration examples. Thresholds never use evaluation labels.

Primary outcomes: fraction of evaluation images whose true label is included under every context (simultaneous coverage); smallest single-context coverage; mean set size averaged over images and contexts; fraction whose predicted class differs across contexts; true-label probability range. Distinguish the envelope threshold deployed with each realized context from the batch-independent intersection set. Report both, not interchangeably. Report all datasets and seeds including negative results.

Secondary outcomes: 50:50 normalization interpolation, first-layer adaptation, group norm, clean source accuracy/AUC; matched-calibration global affine intensity shift clip(0.75*x+0.10) on [0,1]. No claim of arbitrary corruption or unseen-context protection. Batch-size sensitivity at 8 and 32 on seed 0 CNN-BN only. Context generalization to held-out random contexts is empirical, outside the finite-menu theorem.

Statistics: descriptive means and SD across five independently trained seeds. Image-paired bootstrap confidence intervals conditional on trained models/calibration sets; do not pretend repeated contexts or seeds are independent patients. Save per-image probability tensors, exact calibration/test/context indices, training history, checksums and environment lock. Scientific conclusions must respect finite benchmark scope and known derivative theory.

## Feasibility amendment after the first PneumoniaMNIST CNN-BN pilot

The first pilot's outcomes were observed. To keep the full factorial experiment computationally feasible, the primary run evaluates source and target normalization under clean inputs for all 45 models. Mixed/first-layer controls and matched affine-condition evaluations are restricted to seed 0 for both BN architectures; CNN-GN is the companion-independent control. This restriction is based on measured runtime, not on the direction of an observed result. Training remains CPU/two threads; inference uses Apple MPS after a direct CPU comparison gave maximum probability difference 1.72e-6. Pilot probability files are excluded from the release and the primary outputs are regenerated consistently on MPS. Add Corrected Max-Rank (Schlembach et al., 2026) as a dependence-aware comparator after the literature search identified it; all thresholds still use only calibration labels. This document is not a preregistration and its amendment is disclosed.

## Integrity amendment before completing the primary experiment

A label-blind SHA-256 image-byte audit found duplicate images in the source releases, including cross-split overlap. The initial PneumoniaMNIST pilot and first partial training runs are excluded from the final analysis and release. All datasets now undergo exact image-byte de-duplication with training > validation > test priority, including within-split duplicates. This rule uses no labels. Models are retrained from scratch on retained data, validation checkpoint selection is repeated, and calibration/evaluation are repartitioned after de-duplication with seed 20406. Original archive hashes and retained source indices are saved. This does not eliminate unobserved patient/lesion dependence and no such claim is made. The feasibility/pilot amendments are documented rather than represented as preregistered choices.

## Dermatology integrity amendment before any dermatology training

A further literature audit identified known lesion leakage in the original DermaMNIST partitions (Abhishek, Jain & Hamarneh, Scientific Data 2025). The dermatology experiment therefore uses their published DermaMNIST-C 28-pixel archive, not the original MedMNIST archive. Metadata ordering is verified against every diagnosis label, and lesion IDs are checked disjoint across train/validation/test. To avoid repeated-lesion dependence between calibration and evaluation, select the first retained image in published metadata order per test lesion, without consulting diagnosis labels. Training and validation retain all exact-byte-unique images within their lesion-disjoint partitions. Report as DermaMNIST-C, with 8215 training, 573 validation images and 1149 test lesions before any exact-byte filtering. The original dermatology archive is not used for training or results. This amendment follows a data-quality finding, not dermatology outcomes. The primary process was restarted from completed non-dermatology checkpoints to load this correction.

## Exploratory diagnostic analysis amendment during primary training

Add per-class coverage/set-size tables and a held-out-menu diagnostic, without retraining or changing the primary comparison. For the latter, calibrate nominal/envelope thresholds on the first two menu replicates and evaluate simultaneous coverage on the third replicate, using the same held-out query split. The third replica is outside the calibrated finite menu; these are empirical generalization results, not a theorem or basis for method selection. Report every dataset, BN architecture and seed. No context-specific or CMR threshold is transferred to a previously unseen context. This diagnostic was added after pneumonia outcomes, before any diagnostic result inspection.

## Nonconformity-score sensitivity amendment during dermatology training

Add deterministic cumulative-probability/APS scores as an exploratory sensitivity analysis on already saved clean current-BN probabilities, all five seeds and both BN architectures. Sort class probabilities descending with stable class-index tie breaking, then use the cumulative sum through the candidate label; no randomization. Reuse identical calibration/evaluation indices and all five corrections. The primary 1-p score and primary manuscript comparison remain unchanged. Report all score-sensitivity outputs, including potentially uninformative full-label sets. This analysis was added after pneumonia and breast outcomes and before inspecting APS results; no method or score is selected from its evaluation outcomes.

The score sensitivity also includes randomized APS after inspecting deterministic APS outputs (which became full sets on binary tasks). Use a single independent U~Uniform(0,1) per held-out query (seed 90210), shared across all its contexts and classes, and subtract U*p(label) from the deterministic cumulative score. Reuse the same uniforms across training seeds. This preserves the paired companion intervention and augments the exchangeable example with independent randomness. Scores renormalize probabilities in float64 and set the deterministic last cumulative probability to exactly one, avoiding spurious near-one ordering from floating-point summation. Both deterministic and randomized outputs are retained; no primary method is selected from this sensitivity.

## Higher-resolution pretrained-backbone extension (before its outcome inspection)

A runtime-only feasibility check with a synthetic batch of 16 images found that pretrained Torchvision ResNet18 training fits Apple MPS memory and is computationally practical. Add a secondary 224-pixel PneumoniaMNIST experiment with five training seeds 0--4, 5 epochs, AdamW learning rate 1e-4 and weight decay 1e-4, batch 32, all parameters fine-tuned, no augmentation, lowest validation NLL checkpoint. Initialize from official Torchvision ResNet18 IMAGENET1K_V1 weights and replace the final head with two outputs. Replace BN modules with the tested group-isolated inference implementation, preserving original weights/running statistics. Training for this extension uses MPS; this differs from the primary CPU protocol and is reported separately.

Verify the official 224 archive's MD5 and full SHA-256, and assert full label-array/order agreement with the 28-pixel source archive. First apply the primary source-image retained indices to the 224 arrays, then conduct another exact-byte train>validation>test audit at 224 pixels. Store final source indices and any further removals. Repeat grayscale images across RGB channels and use standard ImageNet mean/std normalization. Use the same 12-context design, batch 16, seeds 801--803, and unstratified calibration/evaluation split seed 20406. Evaluate source and current-group BN, all five conformal comparators. This addition is motivated by the low-resolution limitation and measured runtime, not a favorable higher-resolution result. Retain and report all five seeds regardless of outcomes; a pretrained natural-image backbone is not a medical foundation model or diagnostic-resolution clinical validation.

## Companion-pool sensitivity amendment during primary dermatology training

Add seed-0 current-BN inference using validation images as companions, for all three datasets and both BN architectures. These companions were used for checkpoint selection but not gradient-based training; this is not an external clinical cohort. Fix menu seeds and composition as before, independently of calibration/evaluation labels, and recalibrate each comparator with the new menu. Small homogeneous validation pools may require repeated images, recorded in context metadata. Preserve all outputs under p_validpool_target_b16.npz and report all six configurations. This diagnostic was added after primary binary-dataset outcomes to assess dependence on the use of training companions; no primary model/score is selected from the diagnostic.

Runtime amendment: the 224-pixel target-BN inference was accelerated by folding independent query groups into separate channels for native BatchNorm. This preserves each group's reduction domain. On actual held-out queries, maximum probability deviation was 8.35e-7 and inference was approximately three times faster. All 224-pixel target predictions were regenerated with this implementation; trained weights and experimental roles were unchanged. Primary 28-pixel inference retains the original implementation. The benchmark and equivalence test are released.
